# 🧮 Python Calculator

A simple command-line calculator built with Python.

This is my **Day 1 project** in my 160-day Python learning journey.

## 📌 Project Overview

This calculator performs basic mathematical operations based on the user's choice.

The program first asks the user to choose an operation. Then, the user enters two numbers, and the calculator displays the result.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ⚠️ Division-by-zero error handling
- ❌ Invalid choice handling

## 🛠️ Technologies Used

- Python 3

## 🚀 How to Run

1. Make sure Python 3 is installed on your computer.
2. Clone or download this repository.
3. Open the project folder.
4. Run the Python file:

python "Project 1 Smart Calculator.py"

## 💻 Program Flow

1. Choose an operation.
2. Enter two numbers.
3. The program performs the selected calculation.
4. The result is displayed.

## 🧪 Example

Input:

Enter your choice (1 for Addition, 2 for Subtraction, 3 for Multiplication, 4 for Division): 1

Enter two numbers:
10 5

Output:

The result of addition is: 15
